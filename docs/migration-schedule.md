更新日期：2026-10-09

本文把现有前后端切片、剩余工作流和验收条件放进一个有条件的日历窗口。它是工程估算，不代表功能已完成，也不替代代码审查、真实浏览器验收或外部评审。

## 当前范围口径

固定来源路由清单包含 21 个旧路由模块和 4 处主应用直接声明，共 248 个不同的显式 HTTP 方法与路径；当前目标登记 56 个，其中同方法、同路径匹配 56 个，尚未登记 192 个。扣除根路径、健康检查和就绪检查这 3 个基础声明后，未匹配业务/API 声明为 189 个。它们是路由声明数，不是实现进度、已验收请求数或完成百分比；其中还包含运维和基础设施接口。

未匹配声明按来源分布为：series 16、models 9、prompts 8、storyboard 14、chat 16、admin 66、site_config 3、tasks 4、redemption 2、user_preferences 2、teams 25、locks 3、users 2、aistarslab 8、zhangyuge 3、provider_quota 6、files 1，以及 main 中 1 个业务接口。合计 189 个业务/API 声明。任务分页现有前端需要的接口是 GET /api/chat/tasks/list；团队目录接口是 GET /api/teams/my；两者目前都未登记。

页面入口不能按 HTML 文件数计为页面数。当前确认了 index.html、episode.html、reset-password.html 和 admin-panel/index.html 四个产品入口；创作 React 有 LoginPage，以及 SeriesPage、ChapterBrowser、AssetLibrary、MyTasksPage 四个已登记的认证后视图。固定旧后台实际登记 9 个资源、23 个资源视图，另有登录和仪表盘；目标仓库尚未迁入后台页面。已补齐旧入口与十二类工作流到 React 的映射；动态模态框/条件视图未合并为统一功能页面总数，因此不声称页面总完成比例。
