# Spec Delta

## Purpose

让用户从当前剧集的角色、场景或道具目录中显式查看已读取章节快照内的关联镜头文字，按分类和原始素材身份核对引用，保留位置与重复次数，减少逐章人工查找，并明确未找到和无法核对的范围。

## ADDED Requirements

### Requirement: 显式按需读取关联镜头

系统 SHALL 仅在用户打开当前有效素材卡片的关联镜头入口时读取一次当前剧集既有章节列表，不在进入目录、切分类或展示卡片时预读章节。一次只打开一个素材面板，重复选择已打开素材不再次读取；显式重新读取和关闭后重开才读取新快照。

#### Scenario: 目录加载不预读章节
- **WHEN** 用户进入素材库或选择另一素材分类
- **THEN** 系统只保持现有素材目录行为，不发章节、分镜资产、个人记录或粗剪请求

#### Scenario: 打开与重读
- **WHEN** 用户打开一个有效素材的关联镜头入口并在面板内重新读取
- **THEN** 系统分别读取当前剧集章节列表，重读期间旧快照立即隐藏，没有后台轮询或自动重试

### Requirement: 分类原始身份与目录有效性

系统 MUST 按所选分类对应的 character、scene 或 prop 字段与素材原始字符串 ID 精确匹配，不做 trim 后匹配、别名、规范名、名称或其他分类兜底。有效入口 MUST 对应当前目录中唯一原始 ID、同剧集且非空身份的素材；重复身份、错剧集或失效素材不读取章节。

#### Scenario: 同 ID 跨分类
- **WHEN** 三种素材存在相同 ID 而用户打开道具的关联镜头
- **THEN** 系统只扫描 prop 引用，不将 character 或 scene 的同 ID 算入结果

#### Scenario: 身份无法核对
- **WHEN** 当前目录有重复 ID、错剧集素材或空白 ID
- **THEN** 对应卡片提示身份无法核对，没有可触发章节读取的有效入口

### Requirement: 保序文字快照与重复引用

系统 SHALL 保持章节响应顺序及各章节 content 顺序，显示章节标题、章节列表位置、镜头位置、镜头文字和已有原文。每个匹配镜头显示一行，同镜头重复引用按实际出现次数显示；章节位置不由 order 推算。空标题和缺失或坏文字使用占位，文字按字面显示。

#### Scenario: 保序和重复
- **WHEN** 章节响应顺序与 order 不同且一个镜头两次引用该素材
- **THEN** 系统按响应位置显示章节及镜头一次，并显示两次引用，不改变原始数据

#### Scenario: 坏文字与 HTML
- **WHEN** 匹配镜头的文字为缺失、非字符串或含 HTML
- **THEN** 系统分别显示占位或字面文本，不执行 HTML，也不因此丢弃已确认镜头

### Requirement: 局部不确定与空结果

系统 SHALL 将所选分类引用字段 missing、null、空数组视为无引用；非数组或数组内非非空字符串项提示当前快照部分引用无法核对，合法项仍可匹配。零匹配 MUST 表述为当前章节快照未找到关联镜头，不宣称素材从未使用或引用完整。章节列表归属或身份不合法的响应 MUST 不显示成功快照。

#### Scenario: 混合坏项
- **WHEN** 当前分类引用含有效匹配 ID 和无效项
- **THEN** 系统保留已确认镜头并提示存在无法核对的引用信息

#### Scenario: 无匹配或无章节
- **WHEN** 合法章节快照为空或没有匹配引用
- **THEN** 系统显示当前快照未找到关联镜头，若存在坏引用则同时保留不确定提示

### Requirement: 目录与打开上下文隔离

系统 MUST 将素材目录结果和成功缓存绑定当前用户、服务及剧集；变化首次渲染即隐藏旧目录、入口和反查面板，清除旧成功缓存。打开素材的分类、对象、目录快照及本次打开身份 MUST 保持有效；关闭、换素材、实际切分类、目录重读、离开或上下文变化后旧面板永久失效，恢复原上下文不自动重开。普通图片完成或失败 SHALL 不关闭面板。

#### Scenario: 用户或服务变化首帧隔离
- **WHEN** 同一组件的 user 或 services 从 A 变 B 再变 A
- **THEN** 旧目录和面板首次提交即不可见，旧 cache 不复用，用户需在新的有效目录中重新打开

#### Scenario: 切换和目录重读
- **WHEN** 面板打开期间换分类、换素材或显式重读素材目录
- **THEN** 原面板和原请求失效，不能由迟到响应或旧关闭回调覆盖或关闭新的有效面板

### Requirement: 当前请求错误与会话保护

系统 MUST 同时核对当前打开上下文及请求世代，迟到成功、错误或 401 不显示旧内容、不写入可复用结果或注销新会话。仅当前有效 401 触发注销；403、404、422、5xx、超时、网络及无效响应保留会话，给出适当提示和显式重试。

#### Scenario: 关闭后迟到 401
- **WHEN** 用户关闭旧面板并打开新面板或退出后登录新账号，旧请求实际以 401 结束
- **THEN** 当前面板及新会话不受影响

#### Scenario: 当前错误重试
- **WHEN** 当前章节读取发生非 401 错误
- **THEN** 面板保留错误反馈与重新读取入口，会话不被清理，用户显式重试后可恢复

### Requirement: 文字只读与可访问性边界

新增面板 MUST 仅显示文字快照，不显示结构身份、音频/preview/媒体 URL/原始 JSON，不新增图片、音视频或链接，不挂载章节浏览器、复制、下载、编辑、生成或跳转。现有卡片图片行为保持；具名入口、分类和关闭/重读可由键盘操作，390px 不出现横向溢出。

#### Scenario: 只读取既有章节列表
- **WHEN** 用户成功查看素材关联镜头
- **THEN** 新行为只调用现有章节 GET，不增加业务端点、媒体请求或其他制作接口

#### Scenario: 移动与键盘
- **WHEN** 用户在 390px 视口用键盘打开、重读和关闭面板
- **THEN** 内容和按钮可操作且页面无横向溢出
