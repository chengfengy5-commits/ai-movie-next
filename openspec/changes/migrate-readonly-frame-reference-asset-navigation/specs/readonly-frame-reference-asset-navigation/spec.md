# Spec Delta

## Purpose

让用户从章节分镜中已核对的角色、场景或道具引用，直接定位到素材库相应分类里的只读素材卡片。导航使用稳定的原始素材身份和当前用户/剧集上下文，不依赖显示名称、排序或媒体地址。

## ADDED Requirements

### Requirement: 已解析的分镜素材引用提供显式导航入口

当当前章节分镜素材面板和所属类别目录均已就绪，且某条引用已解析为当前剧集中的唯一素材时，系统 SHALL 为该引用提供可访问的“查看素材”导航入口。唯一性先按完整已加载类别目录统计原始素材 ID，再核对所属剧集；名称、别名、标题、位置和图片地址不得作为身份。分镜内同一类别的重复引用 SHALL 按原顺序分别保留，不得因此误判素材身份或额外读取来源数据。

#### Scenario: 打开已解析的角色、场景或道具
- **WHEN** 用户显式打开某条已解析且身份唯一的引用
- **THEN** 系统接受该条引用的类别和原始素材 ID，导航到该素材库分类，并且不写入制作数据

#### Scenario: 同一分镜中有重复的有效引用
- **WHEN** 同一分镜的同一类别多次引用同一个已解析素材
- **THEN** 系统按引用原顺序呈现各行，每行均指向同一稳定素材身份，不额外读取章节或来源目录

#### Scenario: 引用无法唯一核对
- **WHEN** 素材引用未解析、原始素材 ID 为空、类别目录中该 ID 不唯一或素材不属于当前剧集
- **THEN** 系统不显示可导航入口，仅显示不含原始 ID 的说明，且不创建目标导航

### Requirement: 素材库按新鲜目录精确定位目标卡片

系统 SHALL 在已接受的素材导航意图到达素材库后，仅读取目标类别一次新目录，不复用来源目录缓存或预先读取其他类别。系统 SHALL 在完整新目录中统计目标原始素材 ID；仅当其恰好匹配一个且该素材属于当前剧集时，才可定位目标卡片。素材显示名称、别名、标题、列表位置及图片地址 MUST NOT 参与身份匹配。

#### Scenario: 目标素材在新目录中唯一匹配
- **WHEN** 目标类别的新目录包含唯一且属于当前剧集的目标原始素材 ID
- **THEN** 系统显示对应素材卡片，将焦点实际移到目标卡片，确认 `document.activeElement` 为该卡片后才滚动到视口中并消费导航意图

#### Scenario: 目标目录为空或身份缺失、重复、跨剧集
- **WHEN** 新目录为空，或目标原始 ID 缺失、重复，或唯一匹配项属于其他剧集
- **THEN** 系统不定位任何卡片、不消费意图、不按名称或位置回退，并提供安全提示和显式重新核对入口

#### Scenario: 目标卡片未能实际获得焦点
- **WHEN** 身份唯一匹配，但目标节点未连接、不可见，或 `focus` 后 `document.activeElement` 不是目标卡片
- **THEN** 系统不滚动、不消费意图，并保留可理解的未定位状态供用户显式重新核对

#### Scenario: 目录读取失败后显式重试
- **WHEN** 目标类别请求发生非 401 错误或超时
- **THEN** 系统保留当前用户的素材库上下文和目标意图，显示错误与显式重试入口；重试只重新读取该目标类别一次并重新核对完整目录

### Requirement: 导航意图按来源与目标作用域隔离

来源面板位于 `ChapterBrowser` 的章节视图，回调经章节页桥接到 `Workspace`。在接受导航意图之前，来源面板 owner、用户、services、剧集、类别、素材项、目录快照或读取世代发生变化 SHALL 使来源 ticket 失效并拒绝旧回调。工作区 SHALL 仅在捕获的当前 render context 仍为最新对象、视图仍为 chapters、当前剧集匹配且 `can_enter` 为 true 时接受，并复制用户、services、剧集、类别、原始素材 ID 和导航世代；接受后来源面板或章节页卸载/关闭 MUST NOT 撤销已复制的有效意图。目标素材库用户、services 或剧集作用域发生变化时，系统 SHALL 在首个可见提交隐藏旧目录/卡片/反馈，并永久丢弃旧世代；A→B→A 不得重用旧目录、缓存、回调或意图。

#### Scenario: 同一作用域关闭并重新打开后重放旧来源回调
- **WHEN** 用户关闭素材引用面板、重新打开相同素材面板，再调用旧来源回调
- **THEN** 系统拒绝该回调且不产生额外类别 GET 或导航

#### Scenario: 目标用户或 services 变化后旧请求迟到
- **WHEN** 用户或 services 变化后，旧目录 Promise 以成功或 401 实际完成
- **THEN** 系统丢弃旧结果，不覆盖新用户的素材、焦点或反馈，也不注销新会话；当前有效请求的 401 沿用既有认证流程

#### Scenario: 同类别显式重新核对保留未完成意图
- **WHEN** 目标仍未定位时，用户对当前类别显式重新读取或点击“重新核对”
- **THEN** 系统保留同一目标意图，以新请求世代重新读取完整目标类别目录并重新核验；旧请求即使成功或返回 401 也不得提交

#### Scenario: 用户切换类别或离开目标页
- **WHEN** 用户在目标未定位时手动切换到另一素材类别、关闭素材库、返回剧集列表、打开任务页或退出登录
- **THEN** 系统放弃该未完成意图并清除定位反馈；同类别重复点击为无操作。成功定位后普通刷新不得重放已消费意图

### Requirement: 保持既有只读和导航行为

新入口和定位 SHALL 只展示现有素材目录与卡片文字，不增加编辑、写入、锁、播放或导出操作，不新增 image/audio/video 节点、媒体 API 或主动媒体读取逻辑。既有章节级导航 SHALL 保持仅选择章节的语义；本 capability 不改变从素材库查看章节/分镜的既有流程。

#### Scenario: 只读定位不新增媒体或写入路径
- **WHEN** 用户从分镜引用导航到素材卡片并浏览素材库
- **THEN** 系统不新增媒体节点或主动媒体请求，不发起写入、编辑、锁、播放或导出操作

#### Scenario: 原有章节和分镜浏览继续可用
- **WHEN** 用户使用既有章节级或分镜级导航
- **THEN** 系统保留原先的目标选择、加载和只读展示行为，不被新素材导航意图改变
