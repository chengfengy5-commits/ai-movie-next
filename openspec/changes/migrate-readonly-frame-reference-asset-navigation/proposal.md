# Proposal

## Why

章节内的角色、场景和道具引用目前可以查看只读详情，但用户无法从该引用直接打开素材库中的对应卡片。补上精确的只读导航后，用户可以在不改变制作数据的前提下，从分镜引用继续核对素材完整信息。

## What Changes

- 为已解析的角色、场景和道具引用增加显式入口，跳转至素材库对应分类中的精确素材卡片。
- 导航以当前 ready 快照中的原始素材 ID 和完整用户/剧集/分类上下文核验；目标页读取最新分类目录后才定位。
- 对已失效或不唯一的引用保留只读错误提示和显式重核，不按名称、位置或图片回退。
- 保持既有章节级、分镜级导航及素材查看行为，不新增 API、写入操作或媒体读取路径。

## Capabilities

### New Capabilities

- `readonly-frame-reference-asset-navigation`：从章节分镜的已解析素材引用，安全导航到素材库对应分类的只读素材卡片。

### Modified Capabilities

- 无。当前主规格库存为空，本 change 新增独立 capability。

## Impact

影响本地 React 工作台的分镜素材引用面板、素材库、工作区导航和章节/素材视图接线，以及相应的局部组件与集成测试。沿用现有角色、场景、道具目录读取接口和隔离认证状态，不修改后端、DTO、依赖或合成样本。
