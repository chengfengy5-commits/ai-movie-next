# Spec Delta

## Purpose

为当前登录用户提供选中章节个人粗剪草稿的只读核对入口，保留冻结旧接口的顺序、稳定身份与私有归属。通过显式读取、严格结构校验和上下文隔离，展示草稿与当前章节的合并投影，同时避免写入、媒体消费和错误响应被误认为空草稿。

## ADDED Requirements

### Requirement: 显式读取本人章节草稿

系统 SHALL 仅在有效选中章节中提供“查看我的粗剪草稿”入口，打开或用户显式重新读取时调用 GET `/api/chapters/{chapter_id}/rough-cut`，使用当前会话的 Bearer token，不附加查询参数。章节 ID MUST 按路径段安全编码一次，不形成路径穿越或其他路由。系统 MUST 保留服务端的当前用户及剧集访问复验；列表可进入提示不构成后续读取授权。

#### Scenario: 默认不读取与本人隔离
- **WHEN** 用户进入或切换章节但未打开粗剪面板
- **THEN** 系统不发粗剪 GET；打开后只读取本人草稿，隔离 fixture 中两用户的同章结果各自独立，不接受客户端指定他人用户 ID

#### Scenario: 单一读取边界
- **WHEN** 用户打开或重新读取粗剪面板
- **THEN** 系统仅增加该粗剪 GET，不自动读取个人制作记录、追加资产读取、取锁、写草稿或请求视频；既有章节正常读取不变

### Requirement: 严格保留 GET 响应契约

系统 MUST 校验响应自身的必需字段 `chapter_id`、`revision`、`saved`、`frames`、`removed_asset_ids`，以及每项自身必需字段 `asset_id`、`frame_index`、`text`、`preview_url`、`missing_reason`、`included`、`pending`。`chapter_id` MUST 与请求精确相同；`revision` MUST 是非负安全整数，`saved` MUST 是布尔值，未保存对应 revision 0、已保存对应正 revision。每项 `frame_index` MUST 是非负安全整数且不重复，正文和 ID 为字符串，纳入/待安排为严格布尔值，视频引用与原因为显式 nullable string；缺失、undefined 或坏类型 MUST 作为无效响应，不静默补值。非空稳定 ID MUST 唯一；空 ID 多项、重复失效旧引用和超过 500 项的合法 GET MUST 被保留，不套用 PUT 的数量或 ID 长度限制。

#### Scenario: 宽度合法的历史投影
- **WHEN** 合法响应含多个空 asset_id、重复 removed_asset_ids、空正文或超过 500 项
- **THEN** 系统接收并保留响应顺序、条数和原字符串，不按 UUID、最大 36 字符、保存接口上限或数组序号构造新身份

#### Scenario: 无效结构不是空草稿
- **WHEN** 响应缺必需字段、章节不匹配、非空 ID 重复、位置重复、坏布尔/整数/nullable 类型或非法 JSON
- **THEN** 系统显示读取响应不可识别，保留当前会话与显式重读入口，不显示合法空状态或沿用旧草稿

### Requirement: 按读取时投影只读呈现

系统 SHALL 保留 frames 的 wire 顺序，用“草稿列表第 N 项”和“读取时章节第 M 个镜头”区分数组展示序号与原章节位置；位置只由合法 `frame_index + 1` 展示，不作为稳定身份或匹配兜底。系统 SHALL 展示正文、已纳入/已排除、待安排及服务端不可用原因；正文为空时提供占位，所有正文与原因 MUST 按纯文本渲染。`saved=false` SHALL 标记“未保存的初始投影”，`saved=true` SHALL 标记“已保存草稿的当前投影”及版本。失效旧引用 SHALL 仅按数组条数显示，不去重、不展示原始 ID、不推断为相同数量的已删除镜头。

#### Scenario: 新旧分镜合并
- **WHEN** 已保存草稿按旧顺序保留当前有效 ID，并追加 pending=true/included=false 的新项或空 ID 的不可编排项
- **THEN** 系统保持返回顺序，分别显示待安排/排除与不可用原因；不按章节位置重排，不把失效旧引用归给任意现有镜头

#### Scenario: 保存状态与空态
- **WHEN** 响应未保存但含当前帧，或已保存/未保存且 frames 为空
- **THEN** 系统分别展示初始投影及帧列表，或明确的当前投影无镜头空态；不把未保存等同于没有数据

### Requirement: 媒体与写操作保持排除

系统 MUST 明示正文与视频引用来自读取时的当前章节，并非保存时冻结的视频版本；“已纳入”不构成播放、导出或认可资格。系统 MUST 不消费媒体、不展示原始素材 ID 或视频 URL、不将其写入 DOM 属性、日志、链接或媒体元素，不增加播放器、下载、导出、排序编辑、纳入切换、保存、生成、队列、轮询或锁操作。系统 MUST 不把此 GET 称为纯数据库读取：冻结粗剪路由仅查询并在内存合并，认证链仍可能维护 session；本切片不运行真实后端以验证这些副作用。

#### Scenario: 有引用也不消费视频
- **WHEN** 响应包含远端、签名、本地或恶意格式的视频引用，或 included=true 但缺少视频
- **THEN** 系统不播放、不请求、不链接这些值；只呈现只读状态和不可用原因，不使用“可播放/可导出/已认可”承诺

### Requirement: 私有面板生命周期与错误隔离

系统 MUST 将面板绑定当前用户、服务实例、剧集、所选章节对象及本次打开世代；上下文改变的首帧即隐藏旧内容。关闭、切章、章节或原图重新读取、返回/离开章节页、退出、新用户登录或服务实例改变 MUST 关闭并作废面板，终止在途请求；返回或重开不自动恢复草稿，显式打开重新读取。个人制作记录与粗剪面板 SHALL 互斥，打开其一关闭另一且不触发另一接口。重新读取在 pending 时仍可用，MUST 作废旧世代并取消旧请求，不显示前次私有数据。

#### Scenario: 迟到结果不可跨上下文
- **WHEN** 已取消的旧 Promise 在刷新、关闭重开、切章、重读章节/原图、返回换剧集或退出新登录后实际成功或返回 401
- **THEN** 系统忽略旧结果，不污染新面板、不写缓存、不注销新会话；当前有效 401 才使会话失效

#### Scenario: 错误保留会话且仅显式重试
- **WHEN** 当前请求返回会员/普通 403、404、422、500、网络/超时或无效响应
- **THEN** 系统呈现对应读取错误，保留会话、章节与重读入口，不把查询错误变成空草稿或草稿失败；不自动重试、预取或轮询

### Requirement: 隔离验收与既有页面保留

系统 SHALL 默认使用独立无网络 demo 草稿生成器，保留原 24 剧集、默认单一 demo 账号和现有章节样本；显式 API 模式 SHALL 仅连接已允许的相对同源或 loopback 隔离 fixture。新增业务路由后白名单 MUST 恰为 12 种（11 GET + 登录 POST）；fixture 控制仅使用环境变量与重启，不增加控制 HTTP 路由。系统 MUST 保持原六切片导航、团队筛选、剧集已加载数量、个人制作记录、任务页和退出行为；前六 change 历史及 exact-five 来源复制名单不变。

#### Scenario: 桌面移动和验证层级
- **WHEN** 在桌面、390px 移动布局或键盘导航中打开、重读、关闭、返回及退出
- **THEN** 面板可操作、不溢出、不残留隐藏焦点，剧集筛选及展示数量保留；自动测试、隔离真实 HTTP、真实浏览器与未运行真实后端分别记录，Grillme 固定模型的离线待办不被其他层替代
