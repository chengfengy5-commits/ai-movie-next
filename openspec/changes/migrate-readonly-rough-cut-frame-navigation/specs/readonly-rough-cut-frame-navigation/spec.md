# Spec Delta

## Purpose

让用户从本人当前章节的粗剪记录显式定位原章节分镜，以核对草稿编排与分镜内容。定位仅使用当前已读取快照和唯一稳定身份，保留只读面板，拒绝过期上下文、歧义身份和不可聚焦目标，不增加读取、写入或媒体链路。

## ADDED Requirements

### Requirement: 显式定位保持粗剪只读浏览

系统 SHALL 在当前粗剪条目身份可核验且当前章节原图记录已就绪时提供“定位到对应镜头”。仅用户点击才聚焦和滚动；面板、草稿顺序与状态 SHALL 保持。打开面板、读取成功和原图记录完成 MUST NOT 自动定位。定位资格 MUST NOT 依赖 `included`、`pending`、视频 URL、缺视频原因、认可状态或媒体摘要。

#### Scenario: 排除且待安排的无视频条目
- **WHEN** 条目为已排除、待安排或缺视频，但在当前草稿、章节和原图记录中具有可核验的唯一稳定身份
- **THEN** 用户仍能显式定位对应镜头，草稿保持原样，不播放或读取视频

#### Scenario: 原图记录尚未就绪
- **WHEN** 原图记录加载中或读取失败，用户打开粗剪
- **THEN** 系统仍按既有流程读取和显示粗剪，定位不可用且说明等待或无法核对；不为定位补发原图请求

#### Scenario: 普通原图记录完成
- **WHEN** 面板已打开且原图记录的既有在途读取正常成功
- **THEN** 面板保持打开并据当前快照更新定位资格，不重新读取粗剪、不自动聚焦

### Requirement: 三份当前快照按唯一原始身份核验

系统 MUST 使用条目的非空原始 `asset_id`。该 ID 必须在同章当前粗剪快照中唯一、在当前章节的 `storyboard[0]` 中唯一，且在完整当前原图记录响应中唯一；先对全响应计数，再核验匹配记录的章节和剧集归属。系统 SHALL 从匹配章节镜头推导实际位置，MUST NOT 按草稿列表序号、`frame_index`、名称、文本、其他 storyboard ID、UUID 假设或 URL 兜底；不裁剪或归一化原始 ID。

#### Scenario: 草稿顺序与章节顺序不同
- **WHEN** 草稿第一项的稳定 ID 唯一匹配章节第二个镜头，即使展示用 `frame_index` 与当前位置不同
- **THEN** 系统定位章节第二个镜头，以当前章节实际位置显示结果，不将第一项映射成第一镜头

#### Scenario: 身份缺失或歧义
- **WHEN** ID 空白、条目不属于当前快照、草稿或章节重复 ID、原图响应重复 ID、目标缺失或归属不同
- **THEN** 系统不给出有效定位入口或拒绝点击并说明无法核对，不选择相邻镜头、不追加 GET

### Requirement: 定位回调和反馈隔离完整上下文

系统 MUST 将定位绑定当前用户、服务实例、剧集、章节对象、面板打开世代、粗剪读取世代、ready 草稿快照及条目、当前 ready 原图记录快照与对应请求世代。用户、服务或章节对象变化的首个可见提交 SHALL 隐藏并永久关闭旧面板；上下文 A→B→A 不得复活旧回调。关闭重开、粗剪重读、显式章节或原图重读、切章、离开章节、返回列表、进入任务或退出登录 SHALL 作废旧定位与反馈。普通在途原图成功 SHALL 不视为关闭面板的事件。

#### Scenario: 重读后旧回调或响应到达
- **WHEN** 用户重读粗剪或关闭重开后，旧定位、关闭、失效回调或旧成功/401 响应实际到达
- **THEN** 旧内容不得恢复，旧回调不得定位、关闭新面板、清除新反馈或使新会话退出；只有当前读取和当前显式点击有效

#### Scenario: 账号或服务实例往返
- **WHEN** 旧请求尚未完成时用户或服务实例 A→B→A，随后旧 Promise 成功或 401 真正 settle
- **THEN** 旧面板首帧已隐藏且不复活，旧定位不发生，当前会话保持正确；需要重新显式打开粗剪才能开始新读取

### Requirement: 实际焦点成功后才显示定位结果

系统 SHALL 仅定位当前镜头列表内、仍连接且不处于 hidden/inert 区域的实际镜头文章。聚焦前和聚焦后 MUST 重新核验当前所有者、快照、世代、身份与 DOM 节点。实际焦点成功后才滚动到镜头并提供清晰位置反馈，保留粗剪面板。失焦或对应上下文失效 SHALL 清除该反馈；粗剪反馈 MUST NOT 清除其他定位流程的当前反馈。

#### Scenario: 可聚焦目标
- **WHEN** 用户点击合法当前条目且目标实际获得焦点
- **THEN** 系统使用不预先滚动的聚焦及即时居中滚动，显示已定位的实际镜头位置，面板保持打开；用户可再次显式定位而不增加请求

#### Scenario: 目标不可见或聚焦失败
- **WHEN** 目标已经断开、处于隐藏区域、聚焦未生效，或聚焦期间上下文改变
- **THEN** 系统不滚动、不显示成功反馈，保留当前有效面板并提示未定位；不自动重试或发起请求

### Requirement: 保持既有接口与来源边界

本批 MUST 不新增或修改业务 API、DTO、服务、demo/fixture 数据、媒体节点、依赖或来源复制。显式定位和重复定位 SHALL 不增加任何业务 GET。既有十二种业务接口、exact-five 复制名单与前十三批历史保持不变；原图仍沿用既有安全展示。系统 MUST 不将本地身份核验称为认可、可播放、可导出或数据库纯读取证明。

#### Scenario: 定位与既有读取区分
- **WHEN** 用户打开粗剪并点击一个合法定位入口
- **THEN** 打开沿用既有本人粗剪 GET，定位本身新增 GET 为零；没有 notes、锁、写入、播放、下载或外部媒体操作
