# Spec Delta

## Purpose

让用户从角色、场景或道具的只读引用结果定位到当前章节中经身份核验的具体分镜，同时在目标页面重新读取章节和分镜素材，避免把旧快照位置误当作稳定身份。

## ADDED Requirements

### Requirement: 素材引用结果提供经过核验的分镜入口
素材反查面板 SHALL 保留现有“查看对应章节：<标题>”入口，并为每个身份有效的命中分镜提供“定位对应镜头：<章节> · 镜头<n>”入口。分镜入口的章节 ID SHALL 在同一来源章节响应的全部原始 ID 中唯一且属于当前剧集；入口 SHALL 指向同一响应中对应章节的实际 frame 对象。该 frame 的非空 `storyboard[0]` 原始 ID SHALL 在该章节内唯一，且该 frame 的所选类别字段至少包含一次当前素材原始 ID。相同类别字段重复引用该素材 ID 是合法的，不增加入口数，并保留既有投影对引用次数的表现。匹配 MUST 按原始身份精确比较，不得用标题、别名、规范名、frame_index 或列表位置替代。

#### Scenario: 当前引用的多个分镜
- **WHEN** 当前素材目录与 ready 章节快照中存在多个可核验的关联分镜
- **THEN** 面板按现有章节和分镜展示顺序，为每个匹配分镜显示带章节标题和镜头位置的入口；每个入口绑定自己的章节与 storyboard 原始身份

#### Scenario: 分镜身份无法核对但章节有效
- **WHEN** 章节 ID 或 `storyboard[0]` 缺失、重复、跨剧集或不再匹配，或当前类别字段不再包含素材原始 ID
- **THEN** 面板不提供该分镜的定位入口，显示安全的身份核对提示，并保留有效的章节级入口；类别字段中重复出现同一素材 ID 不构成无效身份，且仍只显示一个分镜入口

#### Scenario: 接受前来源入口已失效
- **WHEN** 用户触发分镜入口时，来源 user、services、剧集、素材分类、素材目录、素材项、ready 响应或打开/读取世代已失效，且工作区尚未接受该回调
- **THEN** 系统忽略该回调，不创建导航意图、不改变目标页状态，也不发起额外请求

#### Scenario: 来源卸载后的已接受意图
- **WHEN** 工作区在来源上下文有效时接受分镜意图，随后卸载或关闭素材反查面板，或重放来源的旧关闭回调
- **THEN** 目标页仍按接受时复制的身份重新核对；接受后的来源 `isCurrent` 失效或来源关闭均不撤销、改变该意图

### Requirement: 目标页面以新章节和素材快照定位分镜
目标章节页 SHALL 对每个有效接受的分镜意图重新读取一次当前剧集章节目录。它 MUST 先统计整份新目录中的原始章节 ID，再仅接受全目录中唯一且属于当前剧集的目标章节；MUST NOT 按标题、章节顺序、旧章节位置或临近项回退。随后目标章节中必须存在唯一的非空 `storyboard[0]` ID，且其值匹配意图中的 `storyboardAssetId`；对应 frame 的指定类别字段至少一次包含意图中的 `assetId`。重复出现相同类别素材引用是合法的。章节、分镜 ID 或类别引用在章节快照阶段不匹配时 SHALL 不选中目标章节、不读取分镜素材。

在章节与 frame 身份核对成功后，系统 SHALL 读取该目标章节的现有分镜素材列表一次。新章节的 frame `storyboard[0]` 必须与意图保存的 `storyboardAssetId` 相等；目标素材响应的原始资产 `id` 必须与意图保存的 `storyboardAssetId` 相等，且该 ID 在整份响应中唯一，`series_id`、`chapter_id` 均精确匹配当前目标。类别引用 `assetId` 仅用于确认 fresh frame 仍引用同一类别素材，不与响应资产 `id` 比较。匹配 MUST NOT 依赖 `frame_index`、名称、旧位置或图片地址。章节/frame 前置身份无效时不发起素材 GET；素材响应身份无效时本次唯一素材 GET 已发生。

#### Scenario: 新目录重排且章节或分镜标题相同
- **WHEN** 新章节顺序与来源快照不同，多个章节或分镜标题相同，但目标原始章节 ID 和 `storyboard[0]` 均唯一匹配
- **THEN** 目标页只定位到身份匹配的章节和 frame；该导航读取一次章节目录和一次目标章节素材列表，不按旧位置或 `frame_index` 选择近邻项

#### Scenario: 目标章节身份缺失、重复或跨剧集
- **WHEN** 新章节目录中目标原始 ID 缺失、重复（包括当前剧集与外剧集各有一项）或唯一项属于其他剧集
- **THEN** 页面不选中默认章节、不请求分镜素材、不定位或消费意图，并显示可显式重新核对的提示

#### Scenario: 目标分镜身份或类别引用失效
- **WHEN** 目标章节唯一有效，但目标 `storyboard[0]` 缺失、重复或不匹配，或该 frame 不再包含当前类别素材原始 ID
- **THEN** 系统不选中目标章节、不发起目标章节素材 GET，不定位或消费该意图，并保留明确的重新核对提示；重复出现相同类别素材引用不使身份失效

#### Scenario: 新素材响应无法唯一确认目标
- **WHEN** 目标章节与类别引用已通过核对，但素材响应中目标 `storyboardAssetId` 缺失、重复、属于其他剧集或章节
- **THEN** 系统仅完成这一次目标章节素材 GET；保留已核验的目标章节只读内容及未消费意图，显示未定位提示，不聚焦、不回退到其他素材，并允许用户显式重新核对整个章节→素材流程

#### Scenario: 原图地址不可显示但素材身份有效
- **WHEN** 目标素材身份有效，但对应 image URL 为空、非当前页面可安全显示或图片加载失败
- **THEN** 系统仍可按已核验的文字与身份定位目标 frame，不把图片显示状态当作稳定身份或授权依据

#### Scenario: 来源没有可核验的分镜匹配
- **WHEN** 当前章节快照中无匹配分镜，或用户打开的是保留的章节级入口
- **THEN** 系统只执行对应入口既有行为，不凭空生成分镜意图；章节级入口仍只定位章节，不自动聚焦分镜，也不等待素材读取后才消费章节意图

### Requirement: 分镜导航具有显式加载、重试和身份隔离
接受分镜意图后，目标页 SHALL 隐藏旧章节、旧分镜和旧定位反馈，再执行目标章节目录 GET；不在用户打开有效来源入口之前发起额外来源读取。目录/章节 frame 的前置身份不匹配或章节目录请求发生非 401 错误时，系统 SHALL 不选中目标章节，并保留意图与可理解提示。章节和 frame 已核验后，若素材响应身份不匹配或素材请求发生非 401 错误，系统 SHALL 保留已核验目标章节的只读内容、未消费意图和未定位提示。任何显式重新核对 MUST 从 fresh 章节目录 GET 开始，再按前置身份结果决定是否执行一次目标素材 GET；不得只重试旧素材请求。只有目标 DOM frame 经身份确认并成功聚焦、滚动到视口后，系统 SHALL 消费分镜意图；打开提示、找到同标题内容或选中章节本身均不构成消费。

在工作区接受意图之前，来源面板关闭或来源素材/类别/目录/用户/services/剧集/ready 读取世代变化 SHALL 使来源 ticket 失效并拒绝回调。工作区接受时复制意图身份；接受后来源自然卸载或关闭 MUST NOT 撤销已复制意图。尚未完成的意图受目标页与工作区的 user/services/series/navigationEpoch scope 和用户显式放弃行为约束；退出目标页或手动选择另一合法章节 SHALL 放弃它。已消费的意图不得被普通章节刷新或后续手动选择重放。当前有效请求的 401 SHALL 沿用现有认证流程；失效 scope 的迟到成功或 401 MUST NOT 覆盖新内容、焦点、反馈或注销新会话。

#### Scenario: 章节目录读取发生非 401 错误
- **WHEN** 当前分镜导航的目标章节目录读取发生 403、404、422、5xx、超时、网络或格式错误
- **THEN** 页面不选中默认或其他章节，保留会话和待核对身份，显示显式重新核对入口，不自动重试

#### Scenario: 已核验章节后的素材读取发生非 401 错误
- **WHEN** 目标章节和 frame 前置身份已经核验，但目标素材读取发生 403、404、422、5xx、超时、网络或格式错误
- **THEN** 页面保留该已核验章节的只读内容和未消费意图，显示未定位错误；显式重新核对从 fresh 章节目录 GET 开始，不自动重试

#### Scenario: 显式重读重新核对失败的目标
- **WHEN** 目标章节或素材身份无法确认，用户显式重新核对，且新快照仍无法唯一匹配
- **THEN** 页面继续保留原目标、显示未定位提示且不消费；新鲜目标章节仍唯一匹配且素材也唯一匹配时才继续定位

#### Scenario: 用户选择其他章节
- **WHEN** 待核对分镜意图尚未消费且用户显式选择另一合法章节
- **THEN** 系统放弃该分镜意图，并按普通章节流程显示用户选择项；后续普通重读不再跳回旧目标

#### Scenario: 用户或 services 改变后旧请求迟到
- **WHEN** 用户或 services 变化导致旧分镜导航失效，旧章节或素材 Promise 随后以成功或 401 实际完成
- **THEN** 系统忽略迟到结果，不改变新用户或新 scope 的章节、素材、反馈或会话状态

### Requirement: 已确认分镜提供可访问的只读定位反馈
目标 frame 只有在当前页面仍连接、可见且属于已确认目标章节时 SHALL 尝试键盘聚焦，并提供以章节和镜头位置命名的可访问名称、非 Tab 序列中的可聚焦目标和短暂可见定位反馈。调用 focus 后必须确认 `document.activeElement` 就是目标节点，再次核对 owner、epoch、当前章节和素材快照以及节点可见归属；只有这些检查通过才 SHALL 滚动至当前视口中央并消费意图。焦点未实际转移时不得滚动、显示成功反馈或消费意图。章节读取、分镜素材读取、打开和重读期间旧定位反馈 SHALL 隐藏。新增交互 MUST NOT 显示原始素材 ID、URL 或媒体地址，不新增 image、audio、video 元素、媒体 API 或主动媒体读取逻辑，不增加编辑、锁、写入或播放行为；现有章节页安全 loopback 图片行为保持不变。

#### Scenario: 聚焦成功后定位当前目标 frame
- **WHEN** 新章节及素材快照唯一确认目标，目标 frame DOM 已连接且可见，调用 focus 后 `document.activeElement` 确认焦点已转移，且复核时 owner/epoch/chapter/assets/节点仍当前
- **THEN** 页面将该 frame 滚动到视口中央，显示位置反馈并消费意图

#### Scenario: 无法聚焦当前 DOM frame
- **WHEN** 身份已匹配但目标节点不存在、断开连接、位于 hidden/inert 内容中，或调用 focus 后 `document.activeElement` 不是目标节点
- **THEN** 页面不滚动、不显示成功定位反馈且不消费意图；用户可显式重读后再次核验

#### Scenario: 只读与媒体边界
- **WHEN** 用户浏览或定位素材关联分镜
- **THEN** 页面只显示现有章节文字与安全的定位反馈，不暴露原始 ID/URL，不新增媒体节点/API/主动读取逻辑，也不提供写入、锁定、播放或导出操作；章节页既有的安全 loopback 图片仍沿用原行为
