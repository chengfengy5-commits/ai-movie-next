# Proposal

## Why

素材反查已经能列出关联章节，但用户还需要离开素材页、回到章节列表再逐项查找，才能查看章节上下文。为每个命中的章节提供明确入口，并在目标章节页重新核对当前目录，可减少往返操作，同时避免依赖过期的素材快照。

## What Changes

- 在素材关联章节分组中，为每个章节提供“查看对应章节：<标题>”入口。
- 仅当来源素材和章节仍属于当前用户、剧集及目录范围时接受导航意图；目标页重新读取章节，并按稳定章节 ID 精确打开唯一匹配项。
- 目标缺失、重复或不属于当前剧集时显示可理解的提示，不回退到首章；目标章节内容为空时不读取分镜素材。
- 在加载、错误、重试、切换剧集和会话变化期间隔离旧导航意图，保留现有返回剧集列表与筛选状态行为。

## Capabilities

### New Capabilities

- `readonly-asset-usage-chapter-navigation`: 从素材关联章节只读结果精确导航到当前剧集中的唯一章节。

### Modified Capabilities

无。

## Impact

- 前端素材关联章节面板、工作区导航状态与章节浏览页。
- 复用现有章节列表及分镜素材只读 API；不新增 API、DTO、依赖或素材样本。
- 不改变服务端行为，不新增章节写入、帧级定位、媒体播放或远端媒体请求。
