# Spec Delta

## Purpose

在已加载的章节镜头中，让用户按分类查看该镜头引用的角色、场景和道具文字详情，同时严格保留剧集归属、类型和引用身份。通过明确的未关联、不可识别、无法对应及读取错误状态，避免旧响应或跨类型身份误导用户，并维持隔离只读迁移边界。

## ADDED Requirements

### Requirement: 显式查看与按需分类读取

系统 SHALL 在当前可读取的镜头提供关联素材只读入口；打开面板时不预选分类、不读取素材目录。用户显式选择分类且该分类存在合法引用后，系统 SHALL 仅调用该分类已有的剧集素材列表接口；同次查看中的当前成功目录可以复用，重新读取必须由用户触发。

#### Scenario: 打开与选择

- **WHEN** 用户打开镜头的关联素材面板并随后选择角色分类
- **THEN** 打开动作不发送素材请求，分类选择仅读取角色目录，不预取场景或道具，重复选择当前成功分类不新增读取

#### Scenario: 没有有效引用

- **WHEN** 所选分类缺字段、为 null、为空数组，或没有合法非空字符串引用
- **THEN** 系统明确展示未关联或不可识别状态，不读取该分类目录，不通过其他分类兜底

### Requirement: 按引用身份解析且保留原序

系统 MUST 按当前剧集、分类及原始引用 ID 精确查找唯一素材，保持引用数组原序与重复项。别名与规范名只能作说明，不能替代身份、合并或推断引用。非法引用项 SHALL 局部提示，合法项仍可核对；找不到、重复或归属不符的素材不能被当作有效关联。

#### Scenario: 跨类型同 ID 与重复引用

- **WHEN** 不同分类存在相同 ID，且镜头在同一分类重复引用该 ID
- **THEN** 系统仅使用当前分类的同剧集唯一素材，并按镜头引用原序保留重复展示及现有关联数量

#### Scenario: 缺失或混合格式

- **WHEN** 引用包含合法 ID、空白或非字符串项，或合法 ID 没有匹配素材
- **THEN** 合法项按原序解析，坏项明确提示不可识别，缺失项提示无法对应，不展示原始 ID、不按名称或首素材代替

### Requirement: 文字详情与调用边界

系统 SHALL 仅展示素材名称或标题、别名、描述及人物文字特征；空名称使用分类占位，HTML 作为文字。此面板 MUST NOT 新增图片、音频、视频、媒体链接、播放或写入入口，不显示原始 ID、规范名、音频引用或 JSON，不调用重复检测、排除查询或新接口。

#### Scenario: 素材含媒体与格式化文字

- **WHEN** 成功素材包含图片、音频地址、规范名及 HTML 字符串
- **THEN** 面板只显示允许的文字详情，HTML 不执行，媒体地址不进入新节点或链接，不触发主动媒体读取

### Requirement: 当前快照与生命周期隔离

关联素材面板 SHALL 仅绑定当前用户、服务、剧集、章节及镜头快照与本次打开；位置仅表示当前快照中的镜头位置，不充当持久身份。上下文变化的首帧 SHALL 隐藏并永久失效旧面板，即使上下文恢复也不能自动重开。关闭、另镜头、切章、章节或原图重读、个人面板互斥切换、返回、任务页或退出 SHALL 使旧读取与缓存写入失效。

#### Scenario: 首帧变化及 A→B→A

- **WHEN** 用户、服务或章节对象发生变化后又恢复原值
- **THEN** 旧面板在首个变化提交已隐藏，旧成功内容不可复活，重新查看须显式打开

#### Scenario: 迟到响应及回调

- **WHEN** 旧请求在切分类、重读、关闭重开或新会话之后才成功或返回 401，或者旧关闭回调被重放
- **THEN** 旧结果不能显示或缓存到新面板，不能关闭新面板或注销新会话

### Requirement: 错误与可访问性

系统 SHALL 区分读取中、有效空目录、不可对应引用与网络、格式、权限或服务错误；仅当前有效请求的 401 可触发会话失效，其余错误保留当前会话并提供显式重试。面板和分类入口 SHALL 有明确名称及键盘操作，390px 页面不产生横向溢出；查看素材不得自动定位镜头或改变个人制作状态。

#### Scenario: 当前错误与恢复

- **WHEN** 当前分类读取失败后用户显式重试
- **THEN** 系统展示对应错误及重试，恢复后仍按原引用解析，不自动读取其他分类或修改记录

#### Scenario: 键盘与返回

- **WHEN** 用户以键盘打开并选择分类、关闭面板或返回剧集列表
- **THEN** 用户能识别镜头与分类，关闭后旧内容消失，返回仍保留原剧集筛选和展示数量
