# Proposal

## Why

章节目前只显示分镜关联素材的数量，用户需离开章节并逐一查找名称和详情。在当前镜头内提供关联角色、场景和道具的只读查看，补全章节与已有素材库之间的浏览体验。

## What Changes

- 每个当前镜头增加“查看关联素材”入口，在章节内打开带镜头位置的只读面板。
- 打开时不预选分类、不请求素材；用户选择角色、场景或道具后，只读取该分类已有列表接口，并按当前剧集、分类和引用 ID 精确匹配。
- 保留引用原序和重复项，分别说明未关联、不可识别引用、已移除素材、读取中与读取错误，不按名称、别名、规范名或首项兜底。
- 仅展示文字详情；与个人制作记录、粗剪草稿互斥。切章、重读、离开和会话变化使旧面板与旧响应失效，重新查看需要显式打开。
- 仅对齐现有 demo/fixture 合成引用到同剧集已有素材 ID，保留镜头内容、数量、顺序、媒体、个人记录和草稿。
- 增加身份解析、生命周期、HTTP 路径和真实浏览器验收，记录实际完成层与独立离线待办。

## Capabilities

### New Capabilities

- `readonly-frame-asset-references`: 在当前已加载章节镜头中，按需只读查看其关联角色、场景和道具文字详情。

### Modified Capabilities

无。主规格库仍为空，前八批 change 的规划与历史验证保持原样。

## Impact

影响 React 章节浏览器、新只读面板及局部引用投影、相关自动测试、合成引用与当前文档。不修改服务方法、DTO、个人记录/原图投影、依赖或来源复制；沿用现有十二条业务接口白名单，不查询 duplicates/ignored。
