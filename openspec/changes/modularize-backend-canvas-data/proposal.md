# Proposal

## Why

隔离后端已具备认证、剧集、来源素材及制作记录边界，但章节画布仍留在旧单体路由中。独立承接这两个既有端点，可把共享画布的 HTTP、DTO、序列化、持久化和事务编排放到可审查的模块，同时继续复用现有身份与剧集访问能力。

## What Changes

- 新增 backend-canvas-data 能力，仅承接 GET 和 PUT /api/chapters/{chapter_id}/canvas；画布仍是一章共享的一份文档，不改为用户私有数据。
- 在隔离后端加入 canvas_data 模块、完整画布表投影及六组专项测试；统一应用工厂从当前登记的 52 个路由方法增加到 54 个。该数字是工厂登记数，不表示本批全部通过 TCP 验收。
- 保留固定来源的章节查找、series access、本人锁续期、JSON 编码、大小检查、版本检查、提交后刷新和错误优先级；不增加数据库版本 CAS、自动重试或新的画布格式规则。
- 完成真实 SQLite、HTTP、故障和边界验证后，再按后续授权编写架构说明与验收记录。本次只建立规划，不实施代码或事后文档。

## Capabilities

### New Capabilities

- backend-canvas-data：隔离的章节共享画布读取与保存能力。

### Modified Capabilities

无。本次不修改已存在的主规格。

## Scope

规划允许的后续实现清单为十个新生产模块/文件、六个新测试文件，以及统一工厂和七个既有工厂/边界测试路径，共 24 个实现与测试冻结路径。新增允许修改的既有路径为 `backend/tests/test_chat_data_http.py`：根实际全量回归唯一失败是该测试仍断言 52 个注册方法，而工厂现登记 54 个；仅补充画布 GET/PUT 子集与 54 总数断言，保留原十个聊天方法及其余业务断言。规划中列明的八个既有代码路径仅表示未来允许范围，不代表本次已修改或已授权直接开始实现。五份规划写入后，条件性清单为 452 项；实现阶段预计 468 项；连同两份新说明及四份既有说明的文档冻结预计 470 项。上述均为计划算术，不是当前实测或验收结果。

## Non-Goals

- 不新增画布前端、TypeScript 消费者、渲染器、图结构校验或额外路由。
- 不改变认证、会员、series access、剧集/章节权限、锁策略或画布并发语义。
- 不迁移旧全站 ORM/schema，不声称完成真实 PostgreSQL 并发、生产部署或外部 Grillme 审查。
