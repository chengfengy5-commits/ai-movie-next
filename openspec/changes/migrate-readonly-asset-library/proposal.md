# Proposal

## Why

当前新版工作台已能只读查看剧集、章节与分镜，但用户无法查看剧集内角色、场景和道具。第三切片让用户在同一剧集上下文中浏览已有素材，延续隔离本地验证和逐模块迁移。

## What Changes

- 在允许进入的剧集卡片增加“只读查看素材”，与已有章节入口共享当前剧集上下文；返回保留四筛选及已展示条数。
- 增加角色、场景、道具三个按需切换的只读分类，展示名称、别名、描述、已有角色特征及可信本地图片；保留规范名键和完整响应字段，不计算、合并或改写素材身份。
- 仅增加冻结接口的三个素材列表 GET；保留响应顺序、类型和剧集隔离、独立空态/错误、当前上下文成功缓存及显式重新读取。
- 扩展默认无业务/媒体网络的 demo 与隔离 HTTP fixture，验证真实 fetch、迟到响应、图片失败恢复及真实浏览器行为。
- 不新增搜索、编辑、上传、提取、生成、融合、锁、重复检测/排除查询、音频播放或章节素材名称解析；不扩展来源复制名单，不连接旧服务。

## Capabilities

### New Capabilities

- `readonly-asset-library`: 从剧集进入只读角色、场景、道具浏览，保留冻结 DTO、访问约束、本地媒体及会话/请求隔离。

### Modified Capabilities

无。当前主 specs 为空；本 change 依赖前两切片的工作台、认证、列表和章节实现，不修改它们的历史规划或验收记录。前两切片的 Grillme 离线待办不阻断当前本地开发。

## Impact

影响前端 Workspace/SeriesCard 导航、共享契约与服务层、新素材浏览模块及相关自动测试；隔离 fixture 增加三个 GET 和合成本地图片，当前业务白名单由五条扩展为八条。沿用 React/TypeScript/Vite，不新增依赖或后端副本；真实 FastAPI/PostgreSQL、Worker、R2、生产权限与排序均不在本地 fixture 验收范围。Grillme 仍仅允许 GPT-5.6 Sol / xhigh，离线单列待审。
